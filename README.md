# ระบบรับสมัครนักเรียน นักศึกษา ออนไลน์ (Online Admission System)
### วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ • สำนักงานคณะกรรมการการอาชีวศึกษา (สอศ.)

ระบบรับสมัครและรายงานตัวเข้าศึกษาต่อระดับ ปวช. และ ปวส. (รอบโควตาพิเศษ) พร้อมระบบออกรายงานใบสมัครเป็นไฟล์ PDF มาตรฐานทางการ และแดชบอร์ดสรุปสถิติสำหรับผู้บริหาร/เจ้าหน้าที่

---

## 🌟 ฟังก์ชันเด่น (Key Features)

### 1. ฝั่งผู้สมัครเรียน (Applicant Portal)
- **ฟอร์มรับสมัครแบบ Step-by-Step (4 ขั้นตอน):**
  - เลือกระดับชั้น (ปวช. / ปวส. สายตรง / ปวส. ต่างสาขา) และสาขาวิชาลำดับที่ 1-2
  - กรอกข้อมูลส่วนตัว บิดา มารดา และที่อยู่ติดต่อ
  - ตรวจสอบความถูกต้องของข้อมูล (Data Validation) เช่น เลขบัตรประชาชน 13 หลัก (Checksum Mod 11), หมายเลขโทรศัพท์ 10 หลัก
  - อัปโหลด **รูปถ่ายหน้าตรงขนาด 1 นิ้ว** (ระบบจะดึงภาพไปใส่ในใบสมัคร PDF ทันที) พร้อมเอกสารแนบ ปพ.1, สำเนาทะเบียนบ้าน, เกียรติบัตร
- **ระบบตรวจสอบสถานะการสมัคร (Status Tracking):**
  - ค้นหาด้วยเลขบัตรประชาชน 13 หลัก
  - แสดงสถานะแบบเรียลไทม์ (รอตรวจสอบ, เอกสารไม่ครบ+ระบุข้อความแก้ไข, ผ่านการคัดเลือก, มอบตัวสำเร็จ)
  - ระบบแจ้งเตือนให้ส่งเอกสารซ้ำกรณีเอกสารไม่ครบถ้วน
- **พิมพ์รายงานใบสมัคร (Official PDF):**
  - สร้างไฟล์ PDF ถอดแบบตาม **"ใบสมัครเข้ารับคัดเลือกเพื่อศึกษาต่อเป็นกรณีพิเศษ (โควตา) วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์"**
  - มีตราสัญลักษณ์ สอศ., กรอบรูปถ่าย 1 นิ้ว, ข้อมูลครบถ้วน และเส้นประจุดไข่ปลา
  - รองรับทั้งการสั่งพิมพ์ (Print A4) และดาวน์โหลดไฟล์ PDF โดยตรง

### 2. ฝั่งเจ้าหน้าที่และผู้ดูแลระบบ (Admin Portal)
- **แดชบอร์ดสรุปสถิติ (Real-time Analytics Dashboard):**
  - กราฟแท่ง (Bar Chart) แสดงสถิติการรับสมัคร **แยกตามแผนกวิชา / สาขาวิชา**
  - กราฟโดนัท (Donut Chart) แสดงสัดส่วนตามระดับชั้น (ปวช. vs ปวส.)
  - สรุป 5 อันดับโรงเรียนเดิมที่มีนักเรียนสมัครเข้ามามากที่สุด
  - Admissions Funnel & KPI Cards
- **ตารางจัดการและคัดเลือกผู้สมัคร:**
  - ค้นหาและกรองข้อมูลตามระดับชั้นและสถานะ
  - ดูรูปถ่ายและรายละเอียดผู้สมัคร
  - ปรับเปลี่ยนสถานะ และบันทึกหมายเหตุแจ้งเตือนผู้สมัคร
  - ระบบสร้างรหัสนักศึกษาอัตโนมัติ (Auto-generate Student ID)
  - บันทึกข้อมูลการมอบตัว และพิมพ์ใบมอบตัว / บัตรประจำตัวนักศึกษา
- **ส่งออกข้อมูล (Export Data):**
  - ส่งออกรายชื่อผู้สมัครเป็นไฟล์ Excel (.xlsx) ตามโครงสร้างมาตรฐาน **ศธ.02** ของงานทะเบียน
- **จำลองการแจ้งเตือน (LINE Notify / LINE OA):**
  - ระบบจำลองส่งข้อความผลการสมัครไปยัง LINE ผู้สมัครทันที

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
- **Framework / Runtime:** React 19, Vite
- **Styling:** Tailwind CSS v4, Lucide React (Icons)
- **Charts & Data Visualization:** Recharts
- **PDF Generation:** html2pdf.js, Print CSS A4 Standard
- **Export:** SheetJS (xlsx)
- **Fonts:** Prompt (Modern UI), Sarabun (Official Document)

## 🚀 วิธีการติดตั้งและรันโปรเจกต์ (Installation & Running)

1. **Clone repository:**
   ```bash
   git clone <URL-ของ-Repository-คุณ>
   cd online-admission-system
   ```

2. **ติดตั้ง Dependencies:**
   ```bash
   npm install
   ```

3. **รันเซิร์ฟเวอร์สำหรับ Development:**
   ```bash
   npm run dev
   ```
   เปิดเบราว์เซอร์ไปที่: `http://localhost:5173`

4. **Build สำหรับ Production:**
   ```bash
   npm run build
   ```
